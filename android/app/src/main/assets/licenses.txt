TU VR - The Unlimited Virtual Reality
Open-source licenses
=====================================

TU VR itself is an original application written for this project. Its rendering
pipeline (stereo compositor, lens distortion, head tracking fusion, VR panel UI)
is implemented from scratch in Java + OpenGL ES 2.0 and does not include code or
assets copied from Google Daydream, Cardboard sample apps, Fulldive VR or any
other proprietary VR product.

The application links the following open-source libraries. Each is used
unmodified from its published artifact.

Third-party services
--------------------------------------------------------------------------
TU VR contains no advertising SDK, no analytics SDK and no crash reporting
service. The only network access happens inside the built-in browser, where the
user chooses which page to visit.
